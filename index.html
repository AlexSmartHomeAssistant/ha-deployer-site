Fonctionnement

Le principe

HA-Deployer se connecte à distance à votre instance Home Assistant pour y déployer automatiquement les modules que vous choisissez, sans aucune intervention manuelle de votre part. Un module correspond à un tableau de bord (dashboard) clé en main, dédié à un usage précis (éclairage, météo, sécurité...) : il peut regrouper plusieurs entités, mais aussi des scripts, des automatisations, des capteurs ou des helpers, configurés puis injectés automatiquement sur votre instance à partir des informations que vous renseignez (parfois optionnel).

Tout le nécessaire est inclus : l'installation du magasin HACS s'il n'est pas déjà présent, le téléchargement des cartes personnalisées (custom cards) utilisées par le tableau de bord, ainsi que la mise en place de certaines intégrations requises par le module. Vous n'avez rien à installer vous-même.

Comment ça marche

1. Choisissez vos modules dans l'onglet Module, en renseignant l'entité concernée pour chacun.
2. Ouvrez le Panier (dans le bandeau du haut), validez votre sélection.
3. Renseignez l'URL et le jeton d'accès de votre instance Home Assistant.
4. Procédez au paiement — le déploiement est alors effectué automatiquement à distance sur votre instance Home Assistant.

Lors de cette dernière étape, HACS, les cartes personnalisées et les intégrations dont le module a besoin sont installées automatiquement, avant l'injection du tableau de bord.

Prérequis indispensable : Votre instance Home Assistant doit être accessible depuis l'extérieur pour que le déploiement puisse s'y connecter (choisissez l'une des solutions suivantes) :
  1. Abonnement Nabu Casa (Home Assistant Cloud)
  2. VPN (WireGuard, Tailscale, etc.)
  3. DuckDNS + redirection de port
  4. Cloudflare Tunnel + NGINX (reverse proxy)
Paramètres de Connexion Home Assistant :
  1. Ouvrez votre instance Home Assistant → Cliquez sur votre Profil (en bas à gauche) → Cliquez sur l'onglet Sécurité.
  2. Allez dans l'onglet Jetons d'accès longue durée → Cliquez sur Créer un jeton.
  3. Saisissez le nom HA-Deployer.

À propos

Le projet

HA-Deployer est né d'un constat simple : Home Assistant est extraordinairement puissant, mais construire un tableau de bord soigné demande des heures de YAML, de cartes personnalisées et de réglages.

L'idée est de faire ce travail une fois, proprement, puis de le déployer automatiquement à distance sur l'instance de chacun — avec les bonnes entités, les bons scripts et les bonnes automatisations, adaptés à votre installation.

La partie ingrate est comprise elle aussi : HACS, les cartes personnalisées et les intégrations nécessaires sont installées automatiquement. Aucune préparation technique n'est attendue de votre part.

Vos données

L'URL et le jeton d'accès que vous fournissez servent uniquement à établir la connexion nécessaire au déploiement de vos modules.

Vous gardez la main : un jeton d'accès longue durée se révoque à tout moment depuis votre profil Home Assistant, onglet Sécurité.

Pour suivre la fiabilité des déploiements, nous enregistrons l'issue de chaque tentative : le module concerné, sa réussite ou son échec, et la version de Home Assistant. Ni votre jeton ni l'adresse de votre instance ne sont transmis — seule une empreinte irréversible de cette adresse est conservée, afin de compter les installations distinctes sans jamais pouvoir les identifier.

FAQ

Qu'est-ce qu'un module exactement ?

Un tableau de bord complet dédié à un usage précis. Selon le module, il embarque aussi des scripts, des automatisations, des capteurs ou des helpers, installés automatiquement sur votre instance.

S'y ajoutent les dépendances nécessaires : HACS, les cartes personnalisées et certaines intégrations — le tout compris dans le prix du module.

Dois-je installer HACS ou des cartes moi-même ?

Non, rien n'est à installer manuellement. Si HACS n'est pas encore présent sur votre instance, il est mis en place automatiquement. Les cartes personnalisées utilisées par le tableau de bord sont téléchargées et déclarées dans les ressources Lovelace, et les intégrations requises par le module sont configurées dans la foulée.

Si une de ces dépendances est déjà installée chez vous, elle est réutilisée telle quelle : rien n'est écrasé ni dupliqué.

Mon instance doit-elle être accessible depuis Internet ?

Oui. C'est le seul prérequis technique. Nabu Casa, un VPN, DuckDNS avec redirection de port ou un tunnel Cloudflare conviennent tous. Le détail est sur l'onglet Fonctionnement.

Dois-je obligatoirement renseigner une entité ?

Pas toujours. Les champs à bordure rouge sont obligatoires, ceux à bordure orange sont optionnels — dans ce cas l'entité est détectée automatiquement quand c'est possible.

Le déploiement peut-il casser ma configuration existante ?

Non. Les modules sont ajoutés comme de nouvelles vues dans un tableau de bord dédié. Vos vues et automatisations actuelles ne sont jamais écrasées.

Combien de temps prend un déploiement ?

Quelques minutes après le paiement. Certains modules nécessitent un redémarrage de Home Assistant, effectué automatiquement.

Puis-je essayer avant d'acheter ?

Oui, l'onglet Test Gratuit permet d'injecter un module de démonstration sans engagement.

Comment révoquer l'accès après coup ?

Dans Home Assistant : Profil → Sécurité → Jetons d'accès longue durée, puis supprimez le jeton nommé HA-Deployer. Les modules déjà déployés restent en place.

Aide

Déployer un module, pas à pas

  • Ouvrez l'onglet Module et choisissez une catégorie.
  • Renseignez l'entité demandée, puis cliquez sur Ajouter.
  • Ouvrez le Panier en haut, vérifiez la liste, retirez au besoin.
  • Validez, saisissez l'URL et le jeton de votre instance.
  • Choisissez votre moyen de paiement : le déploiement démarre ensuite.

Obtenir un jeton d'accès

  • Dans Home Assistant, cliquez sur votre Profil (en bas à gauche).
  • Ouvrez l'onglet Sécurité.
  • Section Jetons d'accès longue durée → Créer un jeton.
  • Nommez-le HA-Deployer et copiez la valeur affichée : elle n'est montrée qu'une seule fois.

Résoudre un problème

La connexion échoue : vérifiez que l'URL est complète (avec https:// et le port), et qu'elle s'ouvre bien depuis un réseau extérieur — depuis votre mobile en 4G, Wi-Fi coupé, par exemple.

Le jeton est refusé : il a peut-être expiré ou été révoqué. Générez-en un nouveau puis réessayez.

Une carte affiche « Erreur de configuration » : une carte personnalisée est manquante. Elle est normalement installée automatiquement ; un rechargement forcé du navigateur (Ctrl+Maj+R) suffit le plus souvent.

Si le problème persiste, écrivez à smarthomeassistant.alex@gmail.com en précisant le module concerné.
